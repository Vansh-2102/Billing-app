# 🧾 Billing App – Full Stack Retail POS System

A complete Full Stack Billing / POS (Point of Sale) Web Application built using modern technologies.

This system allows shop owners to manage products, process orders, accept payments (Cash / UPI), and generate printable receipts.

---

## 🚀 Live Demo

🔹 Frontend (Vercel)  
https://billing-app-mu-six.vercel.app  

🔹 Backend (Render)  
https://billing-app-aj2j.onrender.com  

---

## 🏗 Tech Stack

### 🔹 Frontend
- React (Vite)
- Context API (Global State Management)
- Axios (with JWT interceptor)
- Bootstrap
- React Toastify
- Razorpay Checkout

### 🔹 Backend
- Spring Boot
- Spring Security
- JWT Authentication
- Hibernate / JPA
- MySQL
- Razorpay API
- Cloudinary (Image Upload)

### 🔹 Deployment
- Vercel (Frontend)
- Render (Backend)

---

## ✨ Features

### 🔐 Authentication & Security
- JWT-based login system
- Role-based access (ADMIN / USER)
- Secured REST APIs
- Token interceptor in frontend

---

### 📦 Category Management
- Create categories
- View categories
- Auto item count per category

---

### 🛍 Item Management
- Add new items
- Upload item images (Cloudinary)
- Update / Delete items
- Filter items by category

---

### 🛒 Cart System
- Add items to cart
- Increase / Decrease quantity
- Remove item
- Auto calculation:
  - Subtotal
  - 18% GST
  - Grand Total

---

### 💳 Payment Integration
- Cash Payment
- UPI Payment (Razorpay)
- Secure payment verification
- Razorpay Order ID tracking

---

### 🧾 Receipt System
- Auto-generated receipt popup
- Payment details display
- Razorpay IDs for UPI
- Printable receipt
- Auto cart reset after closing receipt
